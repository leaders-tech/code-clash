Build your first Snake bot

This layout is best for beginners because it turns the app into a clear sequence of tasks.

Bot Details

The bot reads one JSON game state from stdin each turn and prints one move: UP, DOWN, LEFT, or RIGHT.

Game State Example

{
  "game": "snake",
  "turn": 12,
  "you": 4,
  "width": 15,
  "height": 15,
  "food": [7, 3],
  "snakes": [
    { "id": 4, "alive": true, "body": [[2, 2], [1, 2]] }
  ]
}
